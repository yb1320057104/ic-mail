iCloud 隐私邮箱管理平台使用文档

本文档面向普通用户，按实际使用顺序说明账号登录、Apple 登录态、隐私邮箱创建、邮件取码、历史同步和自动接码登录。

建议首次使用时依次完成：平台注册 → Apple 新/旧接口登录 → IMAP 取码登录 → 创建或同步隐私邮箱。

一、快速开始

  1. 使用管理员提供的邀请码注册平台账号并登录。
  2. 进入“登录态”，点击右上角“添加账号”。
  3. 输入 Apple ID 和密码，完成新接口或旧接口登录；收到验证码后提交对应验证码。
  4. 如需读取邮件验证码，配置 IMAP 邮箱账号和应用专用密码。
  5. 进入“创建邮箱”选择参与创建的 Apple 账号，或在“邮箱池”同步历史隐私邮箱。
  6. 在邮箱池查看邮件、读取验证码、复制或导出取码地址。

二、注册、登录与平台账号

注册

登录页点击“前往注册”，填写用户名、密码和管理员提供的邀请码。邀请码有效天数从实际使用当天开始计算。

登录保护

登录需要输入图形验证码。用户名或 IP 连续输错密码 5 次后会锁定 10 分钟，请等待倒计时结束再重试。

修改密码

登录后点击右上角“修改密码”。修改成功后，除当前设备外的其他登录会话会退出。

平台公告

管理员发布新公告后，普通用户登录会自动看到弹窗。点击“我已阅读”后，该公告不会再次弹出。

三、Apple 账号与登录态

“登录态”页面按账号展示新接口、旧接口、IMAP、子邮箱数量、保活状态和异常原因。

新增账号

  1. 点击“添加账号”。
  2. 填写 Apple ID、Apple 密码。
  3. 验证码方式选择“短信/手机号验证码”或“受信任设备”。
  4. 点击“新接口登录”或“旧接口登录”。
  5. 收到 6 位验证码后，点击对应的“提交验证码”。

新接口与旧接口

类型主要用途说明
新接口创建隐私邮箱创建效率较高，系统会自动保活。
旧接口创建、读取和同步历史隐私邮箱同步历史邮箱前必须完成旧接口登录。

编辑/重新登录

点击账号行的“编辑/重新登录”，系统会自动带入 Apple ID、IMAP 主机、端口等历史信息。为保护安全，密码不会回填，需要重新输入。

子邮箱数量达到 750 个后会显示“隐私邮件已达上限”，该账号不再参与新邮箱创建。

四、IMAP 取码登录

新旧 Apple 接口用于创建邮箱；真正读取转发邮件和验证码需要 IMAP。

  1. 在账号编辑弹窗选择邮件服务，例如 iCloud、QQ、Gmail、Outlook 或自定义 IMAP。
  2. 填写邮箱账号、登录用户名、IMAP 服务器和端口。
  3. 填写邮箱服务商提供的应用专用密码或授权码，不要使用不支持 IMAP 的普通密码。
  4. 点击“保存取码登录”，再点击“检测取码登录”。
QQ 邮箱通常使用 imap.qq.com:993，并使用 QQ 邮箱设置中生成的授权码。iCloud 使用 imap.mail.me.com:993 和 Apple App 专用密码。

五、自动接码登录功能

当新接口或旧接口登录态失效时，系统可以从接码服务获取短信验证码并自动重新登录。

  1. 打开账号“编辑/重新登录”。
  2. 在“自动接码登录功能”填写 手机号----https://接码地址。
  3. 首次绑定填写 Apple ID 密码并选择“启用”。
  4. 点击“保存自动接码登录”。

接码地址支持两种响应：

响应示例
JSON{"code":"691288"}，系统读取根节点的 code。
普通文本【Apple】验证码为 691288，请勿泄露，系统提取正文中的 4–8 位数字。
自动登录只支持短信/手机号验证码。接码地址必须是 HTTPS 公网地址；首次绑定必须输入 Apple ID 密码。

六、创建隐私邮箱

  1. 进入“创建邮箱”。
  2. 填写标签和备注，选择创建接口。
  3. 勾选参与创建的 Apple 账号。
  4. 点击“开始创建”。每个勾选账号会执行一轮并显示成功或失败。

定时创建可设置执行间隔和每轮间隔。刷新页面不会停止服务器上的定时任务，需要点击“停止定时创建”才能结束。

七、隐私邮箱池

邮箱池支持跨页搜索，并可按邮箱状态、API 状态、iCloud 状态、接码状态、导出状态和收件数筛选。

单个邮箱操作

可以复制 API、读取验证码、同步邮件、查看邮箱、删除已同步邮件、修改状态或停用 API。

批量操作

勾选邮箱后可批量设为可用/已使用/停用，批量导出 API、只导出邮箱，或批量删除本地邮箱记录。

删除邮箱或邮件可能无法恢复，请先确认选中范围并按需导出备份。

八、同步历史隐私邮箱

如果 Apple 账号以前已经创建过隐私邮箱，可以选择登录态并点击“同步该登录态全部历史隐私邮箱”。

系统会先检测旧接口是否已登录，然后显示同步进度、新增、更新、跳过和失败数量。如果长时间停留在连接状态，请查看失败提示并重新登录旧接口。

九、验证码、邮件查看与导出

读取验证码

邮箱池点击“验证码”会同步最新邮件并显示验证码；点击验证码可以复制。

查看邮箱

点击“查看邮箱”可以查看已经同步到本地的主题、发件人、时间和可视化 HTML 正文。

三种 API 导出方式

方式用途
JSON 取码地址程序调用，返回结构化验证码数据。
邮件可视化地址浏览器直接查看最近邮件。
邮件内容地址读取最近邮件正文内容。

导出过的邮箱会显示“已导出”标记，可使用已导出/未导出筛选。

十、邀请码续期

普通用户右上角会显示到期时间，并提供“邀请码续期”按钮。未到期时也可以使用其他未使用的邀请码提前续期。

提前续期按剩余时间叠加。例如当前还剩 12 天，使用 30 天邀请码后，新的到期时间约为 42 天后。

同一账号不能重复使用同一个邀请码；已禁用、已过期或次数已用完的邀请码不能续期。

十一、状态说明与故障排查

提示处理方法
新接口/旧接口登录态异常查看账号状态下方中文原因，点击“编辑/重新登录”重新完成对应接口登录。
IMAP 认证失败确认 IMAP 已开启、服务器和端口正确，并重新生成授权码或应用专用密码。
当前不可接码先修复所属账号的 IMAP 取码状态，再重新同步邮箱。
等待短信验证码超时检查接码 URL 是否能返回最新验证码，并确认 JSON 包含 code 或文本含数字验证码。
同步历史邮箱 504/超时先检测旧接口登录态，重新登录后分账号同步。
隐私邮件已达上限改用其他未达到 750 个子邮箱的 Apple 账号。

十二、安全说明

  • 不要向他人泄露 Apple 密码、2FA 验证码、IMAP 授权码、邮箱 API 地址或邀请码。
  • 自动接码登录中的 Apple 密码和完整接码地址会加密保存，页面只显示脱敏信息。
  • 修改平台密码后，其他设备的登录会话会退出。
  • 在公共电脑使用后请点击“退出”。

十三、常见问题

为什么 Apple 登录正常但收不到邮件？

Apple 新旧接口和 IMAP 是独立状态。创建接口正常不代表 IMAP 可以收件，请单独检测 IMAP。

为什么 QQ 邮箱官网能看到邮件，项目里同步不到？

检查 QQ 邮箱 IMAP 是否开启、是否使用授权码，以及项目配置的邮箱账号、用户名和服务器是否一致。

为什么验证码提交后失败？

确认验证码对应当前登录请求且未过期；如果选择短信验证，请不要提交受信任设备上显示的验证码。

自动接码地址能返回完整短信吗？

可以。系统会从普通文本中提取 4–8 位数字；如果使用 JSON，请将验证码放在根节点 code 字段。
